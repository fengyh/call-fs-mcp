\section{吊挂系统 JAR 包简介}
\bf{主要功能}有3个：1）衣架入库时计算运输的目标库位，2）衣架出库时计算运输的起始库位、待出库衣架编号、阻挡衣架（存储杆中排在待出库衣架之前的衣架）列表，3）以及运输的路径求解。

\bf{JAR包的形态}：JAR包工程编译后，生成两个.Jar文件：\bf{Algorithm-1.0.jar}和\bf{Algorithm-1.0-sources.jar}。前者可用于吊挂系统的对接和集成，后者是用于参考和调试的源代码包。

\bf{JAR包的特性}：1）普适性：设计的目标是，通过配置基础数据，满足不同场景的吊挂硬件系统的业务调度和排产。2）可维护性：可根据吊挂业务系统的功能需求，对JAR包（源代码）进行扩展和调整，例如业务数据的维护和共享方式。

\subsection{3个基础数据表}
\begin{enumerate}[label=\arabic*)]
	\item \bf{节点表}：每个吊挂主轨上按逆时针排列的衣架进出轨的节点的列表。节点的具体的数据组成见后序章节\todo{引用后序章节号}。
	\item \bf{桥接表}：主轨之间的通道（桥接杆），主要指回流通道和快速通道，桥接表无顺序要求。桥接杆的具体的数据组成见后序章节\todo{引用后序章节号}。
	\item \bf{库区表}：主轨之间用于存放衣架的存储杆，包括空衣架和已挂片衣架，库区无顺序要求。库区的具体的数据组成见后序章节\todo{引用后序章节号}。
\end{enumerate}

\subsection{2个业务数据表}
\tbc{文档组织确认：业务数据主要是吊挂系统维护，JAR包需要查询哪些数据？}
\begin{enumerate}[label=\arabic*)]
	\item \bf{库存表}：库存表是指在吊挂软件启动时，车缝站、存储杆中存储的衣架库存数据。对于车缝站，包括\it{站内衣架数量 \& 队列}、\it{待出站衣架数量 \& 队列}、\it{在途衣架数量 \& 队列}、\it{在库衣架数量}。对于存储杆，包括\it{库内数量 \& 队列}、\it{在途衣架数量 \& 列表}。具体的数据组成和数据结构见后序章节\todo{引用后序章节号}。
	\item \bf{排产数据}，此处的排产单包含两种：
	\begin{itemize}
		\item 在吊挂软件启动时，正在执行的排产单，在JAR包初始化时，需要恢复排产单各工序的状态。
		\item 在吊挂软件启动后，下发的新排产单。
	\end{itemize}
	
\end{enumerate}
