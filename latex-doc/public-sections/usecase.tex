\subsection{加载模型}
\begin{figure*}[!h]
	\centering
	\resizebox{1.0\linewidth}{!}{\input{out/uml/mcp/usecase/loadModel/loadModel.latex}}
	\caption{加载模型用例时序图}\label{fig:loadModel}
\end{figure*}
时序图中各序号消息说明如下：
\begin{enumerate}[label=\arabic*)]
	\item 用户在 WEBUI（模型库页）点击"仿真"，传入模型库记录 \texttt{id} 与 \texttt{loadInUI} 是否加载模型到FS的画布\footnote{\bf{loadInUI} 为 \texttt{true} 时，模型将加载到 FS 的画布，false 时不加载。建议只在调试WebAPP期间加载，生产环境不加载减少服务器资源开销。}；
	\item WEBUI 调用 JsApi 封装的 \texttt{fsSimLoadModel(\{id, loadInUI\})}；
	\item JsApi 向后端发送 \texttt{POST /fscloud/sim/loadModel}（axios，带登录态）；
	\item Controller（\texttt{SimController.loadModel}）通过 Service 按 \texttt{fileId} 查询模型库记录（\texttt{fsModelFileService.getById}）；
	\item Service 查询数据库表 \texttt{fs\_model\_file}；
	\item 数据库返回模型库记录（含模型文件相对路径、所属 \texttt{userId} 等）；
	\item Service 将模型记录返回给 Controller，Controller 拼接模型文件绝对路径（\texttt{\{static-path\}} \texttt{uploaded/\{userId\}/\{model\}}）；
	\item Controller 通过 Service 调用 MCP 客户端 \texttt{mcpClientService.loadModel(userId, recordId, modelFileName, loadInUI)}；
	\item Service 向 FS 发送 MCP \texttt{tools/call}（工具 \texttt{loadRemoteSimulationModel}，HTTP JSON-RPC + \texttt{X-API-Key}）；
	\item FS 引擎加载 \texttt{.fs} 文件、创建 \texttt{SimulationModel}，返回 \texttt{modelId}、\texttt{status="LOADED"} 等；
	\item Service 将 MCP 业务 JSON（\texttt{success/code/message/data}）返回给 Controller；
	\item Controller 通过 Service 回写数据库（保存 \texttt{modelId}、\texttt{sim\_status=SIM\_STATUS\_WAITING}）；
	\item Service 更新 \texttt{fs\_model\_file} 表（\texttt{UPDATE}）；
	\item Controller 向前端返回 \texttt{LoadModelDto}（\texttt{modelId}、\texttt{recordId}、\texttt{status}、\texttt{message} 等）；
	\item WEBUI 修改模型库对应模型的状态，并跳转到仿真控制页，展示已加载模型信息（模型状态卡片），用户可在次启动仿真。
\end{enumerate}

\subsection{启动仿真}
\begin{figure*}[!h]
	\centering
	\resizebox{1.0\linewidth}{!}{\input{out/uml/mcp/usecase/runModel/runModel.latex}}
	\caption{启动仿真用例时序图}\label{fig:runModel}
\end{figure*}
\bf{触发条件}：用户在仿真控制页（\texttt{simcontrol/index.vue}）点击按钮 1（\texttt{btn1Click}，其显示名称 \texttt{btn1Text} 为"启动"；状态为运行中/暂停时显示"暂停"/"继续"，此时不会触发本用例）。\bf{按钮状态说明}：仿真启动前（已加载 \texttt{SIM\_STATUS\_WAITING} 或已结束 \texttt{FINISHED}）"停止"按钮 \texttt{btn2} 为\it{禁用}、"重置"按钮 \texttt{btn3} 为\it{可用}；仿真运行中（\texttt{GOING}）或暂停（\texttt{PAUSED}）时"停止"为\it{可用}、"重置"为\it{禁用}。时序图中各序号消息说明如下：
\begin{enumerate}[label=\arabic*)]
	\item 用户点击"启动"按钮（\texttt{btn1Click}），因当前状态为已加载（\texttt{SIM\_STATUS\_WAITING}），进入 \texttt{doRun()}；
	\item WEBUI 调用 JsApi 中的 \texttt{fsSimRunModel(\{id, modelId, showAnimation\})}（\texttt{showAnimation} 来自"开动画"复选框）；
	\item JsApi（\texttt{fsSimApi.js}）向后端发送 \texttt{POST /fscloud/sim/runModel}（axios，带登录态）；
	\item Controller（\texttt{SimController.runModel}）通过 Service 调用 \texttt{mcpClientService.startSimulation}（参数：\texttt{userId}、\texttt{modelId}、\texttt{showAnimation}）；
	\item Service 向 FS 发送 MCP \texttt{tools/call}（工具 \texttt{startRemoteSimulation}，HTTP JSON-RPC + \texttt{X-API-Key}）；
	\item FS 引擎启动仿真线程，返回 \texttt{runId}（本次运行 ID）、\texttt{status="RUNNING"} 等；
	\item Service 将 MCP 业务 JSON（\texttt{success/code/message/data}）返回给 Controller；
	\item Controller 更新内存态 \texttt{SimulationModelTrackingMap}，并通过 Service 回写数据库（\texttt{sim\_status}、\texttt{sim\_times} 等，\texttt{fs\_model\_file} 表）；
	\item Controller 向前端返回 \texttt{RunModelDto}（\texttt{runId}、\texttt{status}、\texttt{message} 等）；
	\item JsApi 中的 \texttt{store}（\texttt{myModel}）保存本次 \texttt{runId}（\texttt{myModel.runId}），供事件回放等后续功能使用；
	\item JsApi 中的 \texttt{mqttClient} 通过 WebSocket 订阅 \texttt{factory/sim/\{userId\}/\{modelId\}/\#}（状态/进度/控制台/动画）；
	\item FS 经内置 MQTT Broker 发布 \texttt{status/progress/console} 消息（前端 \texttt{mqttClient} 与后端 \texttt{MqttClientService} 各自独立订阅）；
	\item \texttt{store} 根据收到的 \texttt{status/progress/console} 更新 \texttt{simStatus}、\texttt{simTime}、\texttt{consoleLog} 等；
	\item WEBUI 状态卡片显示"运行中"（\texttt{SIM\_STATUS\_GOING}），\texttt{btn1Text} 变为"暂停"；
	\item 用户看到仿真已启动，可继续执行暂停/停止/重置等操作。
\end{enumerate}

\subsection{动画显示和高清静态图显示与取消}
\begin{figure*}[!h]
	\centering
	\resizebox{1.0\linewidth}{!}{\input{out/uml/mcp/usecase/animationDisplay/animationDisplay.latex}}
	\caption{动画显示和高清静态图显示与取消用例时序图}\label{fig:animationDisplay}
\end{figure*}
\bf{触发条件}：本用例由\it{上游用例"启动仿真"}触发——启动仿真并开启动画（\texttt{showAnimation=true}）后，FS 开始推送动画帧；页面上的"开动画"复选框控制动画开关、"显示高清静态图"复选框控制 SVG 高清图显示/取消。时序图中各序号消息说明如下：
\begin{enumerate}[label=\arabic*)]
	\item 上游用例"启动仿真"完成后（\texttt{showAnimation=true}），FS 开始产生动画数据（虚线表示由上游用例触发）；
	\item FS 经内置 MQTT Broker 向前端 \texttt{mqttClient} 推送动画帧（JPEG 二进制）与 \texttt{frameMeta}；
	\item JsApi 中的 \texttt{mqttClient} 将 JPEG 帧转为 \texttt{Blob URL}；
	\item WEBUI 显示动画帧（\texttt{myModel.animationFrameUrl}）；
	\item 用户勾选/取消"开动画"复选框（\texttt{showAnimationEnabled}）；
	\item WEBUI 调用 \texttt{fsSimSetAnimationEnabled(\{modelId, enabled\})}；
	\item JsApi 向后端发送 \texttt{POST /fscloud/sim/setAnimationEnabled}；
	\item Controller 通过 Service 调用 \texttt{mcpClientService.setAnimationEnabled}；
	\item Service 向 FS 发送 MCP \texttt{tools/call}（工具 \texttt{setRemoteSimulationAnimationEnabled}）；
	\item FS 返回动画开关状态（\texttt{event=simulationAnimationChanged}）；
	\item Service 将业务 JSON 返回给 Controller，前端据此后继续/停止接收动画帧；
	\item 用户勾选/取消"显示高清静态图"复选框（\texttt{showHdImage}）；
	\item WEBUI 调用 \texttt{fsSimGetSvgPicture(\{modelId, layerId\})}；
	\item JsApi 向后端发送 \texttt{POST /fscloud/sim/getSvgPicture}；
	\item Controller 通过 Service 调用 \texttt{mcpClientService.getSvgPicture}；
	\item Service 向 FS 发送 MCP \texttt{tools/call}（工具 \texttt{getSvgPicture}）；
	\item FS 返回当前层 SVG 数据（\texttt{data.svg}，原始 XML）；
	\item Service 将业务 JSON 返回给 Controller；
	\item WEBUI 将 SVG 转 \texttt{data:image/svg+xml} 显示；取消勾选时清除并恢复 JPEG 动画帧。
\end{enumerate}

\subsection{切换图层}
\begin{figure*}[!h]
	\centering
	\resizebox{1.0\linewidth}{!}{\input{out/uml/mcp/usecase/switchLayer/switchLayer.latex}}
	\caption{切换图层用例时序图}\label{fig:switchLayer}
\end{figure*}
\bf{触发条件}：图层列表的\it{获取与显示}由页面初始化（\texttt{initPage} 调用 \texttt{loadAnimationLayers}）和 MQTT \texttt{animation/layers} 主题（Retain）推送完成，\bf{非用户操作触发}；用户选择目标层（\texttt{switchAnimLayer}）才触发切换动作。\par 时序图中各序号消息说明如下：
\begin{enumerate}[label=\arabic*)]
	\item 页面初始化时 WEBUI 调用 \texttt{loadAnimationLayers()}（非用户操作）；
	\item WEBUI 调用 \texttt{fsSimListAnimationLayers(\{modelId\})}；
	\item JsApi 向后端发送 \texttt{POST /fscloud/sim/listAnimationLayers}；
	\item Controller 通过 Service 调用 \texttt{mcpClientService.listAnimationLayers}；
	\item Service 向 FS 发送 MCP \texttt{tools/call}（工具 \texttt{listRemoteSimulationAnimationLayers}）；
	\item FS 返回动画层级（\texttt{layers}：\texttt{layerId}、\texttt{name}、\texttt{frameTopic} 等）；
	\item Service 将业务 JSON 返回给 Controller；
	\item JsApi 中的 \texttt{store} 保存层列表（\texttt{myModel.animationLayers}）；
	\item FS 经 MQTT \texttt{animation/layers} 主题（Retain）推送层目录，\texttt{mqttClient} 收到后再次更新 \texttt{store}（非用户操作）；
	\item WEBUI 展示层级列表（模型树/下拉）；
	\item 用户点击目标层（\texttt{switchAnimLayer(layerId)}）；
	\item WEBUI 调用 \texttt{fsSimSelectAnimationLayer(\{modelId, layerId, frameRate:5\})}；
	\item JsApi 向后端发送 \texttt{POST /fscloud/sim/selectAnimationLayer}；
	\item Controller 通过 Service 调用 \texttt{mcpClientService.selectAnimationLayer}；
	\item Service 向 FS 发送 MCP \texttt{tools/call}（工具 \texttt{selectRemoteSimulationAnimationLayer}）；
	\item FS 切换当前活动动画层；
	\item Service 将业务 JSON 返回给 Controller；
	\item JsApi 中的 \texttt{store} 更新 \texttt{animationActiveLayer}；
	\item FS 向 \texttt{mqttClient} 推送新层的动画帧/对象帧（MQTT）；
	\item WEBUI 显示新层画面；若处于高清模式则重新获取新层的 SVG。
\end{enumerate}

\subsection{关闭模型}
\begin{figure*}[!h]
	\centering
	\resizebox{1.0\linewidth}{!}{\input{out/uml/mcp/usecase/closeModel/closeModel.latex}}
	\caption{关闭模型用例时序图}\label{fig:closeModel}
\end{figure*}
\bf{触发条件}：用户在仿真控制页点击"关闭"按钮（\texttt{doClose}）即触发本用例——关闭即卸载当前模型，并清理前端状态、返回模型库页。时序图中各序号消息说明如下：
\begin{enumerate}[label=\arabic*)]
	\item 用户点击"关闭"按钮（\texttt{doClose}），页面提示"正在关闭..."；
	\item WEBUI 调用 JsApi 中的 \texttt{fsSimUnloadModel(\{id, modelId\})}；
	\item JsApi（\texttt{fsSimApi.js}）向后端发送 \texttt{POST /fscloud/sim/unloadModel}（axios，带登录态）；
	\item Controller（\texttt{SimController.unloadModel}）通过 Service 调用 \texttt{mcpClientService.unloadModel(userId, modelId)}；
	\item Service 向 FS 发送 MCP \texttt{tools/call}（工具 \texttt{unloadRemoteSimulationModel}，HTTP JSON-RPC + \texttt{X-API-Key}）；
	\item FS 卸载模型（若正在运行/暂停会先 \texttt{stop}），从内存移除模型实例；
	\item FS 返回卸载结果（\texttt{userId}、\texttt{recordId}、\texttt{modelId}、\texttt{uiLoaded} 等）；
	\item Service 将 MCP 业务 JSON（\texttt{success/code/message/data}）返回给 Controller；

\subsection{横向对比模式分析结果}
\begin{figure*}[!h]
	\centering
	\resizebox{1.0\linewidth}{!}{\input{out/uml/mcp/usecase/compareMode/compareMode.latex}}
	\caption{横向对比模式分析结果用例时序图}\label{fig:compareMode}
\end{figure*}
\bf{触发条件}：用户在仿真数据页选择"横向对比模式"（\texttt{radio: compare}）并勾选\it{两个快照}（第 1 个为主体、第 2 个为对照）后自动触发对比分析。\bf{说明}：\it{参数快照与结果快照是成对出现的}——保存结果快照时两者成对落库，对比分析时按快照成对取出参数与结果。前端处理是本用例重点：\texttt{loadCompareBoth} 一次构建参数对照与结果对照两页，切换二级页仅显示切换、零请求；对照数据缓存于 \texttt{compareRowsCache}。时序图中各序号消息说明如下：
\begin{enumerate}[label=\arabic*)]
	\item 用户选择"横向对比模式"（\texttt{mode='compare'}）；
	\item 用户勾选两个快照（第 1 个为主体、第 2 个为对照），勾满后调用 \texttt{loadCompareBoth()}；
	\item \texttt{loadCompareBoth} 先加载结果侧：主体快照数据（当前 $\rightarrow$ MCP 获取；历史 $\rightarrow$ 数据库 \texttt{getResultSnapshotById}）；
	\item 结果侧再取对照快照的元信息（\texttt{compareRefMeta}，经 \texttt{getResultSnapshotById}）；
	\item \it{参数侧}：\texttt{loadParamCompare} 用 \texttt{Promise.all} \it{并行}取两个快照的\it{成对参数表}（主体 \texttt{paramMainTables}、对照 \texttt{paramRefTables}）；
	\item 参数表来源：当前快照 $\rightarrow$ MCP \texttt{getRemoteSimulationParameterSnapshot}；历史快照 $\rightarrow$ 数据库成对参数快照（\texttt{getSnapshot}）；
	\item 前端保存两页数据：结果侧 \texttt{compareRowsCache}、参数侧 \texttt{paramMainTables}/\texttt{paramRefTables}；
	\item WEBUI 展示二级 tabs：\it{参数对照}（默认）/\it{结果对照}，切换仅显示切换、数据不重新请求；
	\item 结果对照页按 dataset 展示主体数据，对照数据由 \texttt{ensureCompareRows} 懒加载：分页调用 \texttt{getResultDatasetPageInDb}（\texttt{limit=1000}，上限 500 页防失控）拉取对照快照该 dataset 全量并缓存；
	\item 表格按 \texttt{compareKey}（如 \texttt{objectName}）对齐，并排展示两快照的同字段数值，便于横向分析；
	\item \bf{注意}：\texttt{compareKey} 为空串的 dataset 不做横向对比，对比模式下只显示主体快照；当前仿真行可作主体（第 1 个），但不能作对照（第 2 个）。
\end{enumerate}
