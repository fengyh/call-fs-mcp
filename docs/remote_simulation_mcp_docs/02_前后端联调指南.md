# 远程仿真前后端联调指南

日期：2026-06-16

## 1. 推荐架构

前端不要直接调用 MCP。推荐由云端后端封装 REST 或 WebSocket。

```text
Vue
  -> Backend API
  -> MCP tools/call
  -> FactorySimulation
```

前端只关心后端提供的业务接口，例如：

- `POST /api/simulations/load`
- `POST /api/simulations/{modelId}/start`
- `POST /api/simulations/{modelId}/pause`
- `POST /api/simulations/{modelId}/resume`
- `POST /api/simulations/{modelId}/stop`
- `POST /api/simulations/{modelId}/reset`
- `GET /api/simulations/{modelId}/status`
- `GET /api/simulations/{modelId}/snapshot`
- `DELETE /api/simulations/{modelId}`

这些 REST 路径不是本轮 Java 代码新增接口，只是建议云端后端给前端封装的接口形态。

## 2. 前端页面建议

第一期 MVP 页面可以很简单：

- 模型选择或模型文件名输入
- 加载模型按钮
- 当前模型状态区域
- 启动、暂停、恢复、停止、重置、卸载按钮
- 结果快照区域
- 错误提示区域

建议前端状态机：

```text
未加载
  可操作：加载

LOADED
  可操作：启动、重置、卸载

RUNNING
  可操作：暂停、停止、查询状态、查询结果快照

PAUSED
  可操作：恢复、停止、查询状态、查询结果快照

FINISHED
  可操作：查询结果快照、重置、卸载、再次启动

STOPPED
  可操作：查询结果快照、重置、卸载、再次启动

FAILED
  可操作：查询状态、查询结果快照、重置、卸载
```

## 3. 前端展示字段

状态卡片建议展示：

- `modelId`
- `modelFileName`
- `status`
- `runId`
- `simTime`
- `message`
- `loadedAt`
- `startedAt`
- `finishedAt`

结果卡片建议展示：

- `totalOutput`
- `throughputPerHour`
- `currentWip`
- `simTime`
- `status`
- `message`

时间字段：

- `loadedAt`
- `startedAt`
- `finishedAt`

当前是 Java `System.currentTimeMillis()` 毫秒时间戳，前端自行格式化。

`simTime` 是仿真时间，单位按当前 FactorySimulation 引擎内部 `long` 时间体系处理。现有吞吐计算按毫秒换算小时：

```text
throughputPerHour = totalOutput * 3600000.0 / simTime
```

## 4. 后端 REST 封装建议

### 4.1 加载模型

前端请求：

```http
POST /api/simulations/load
Content-Type: application/json
```

```json
{
  "userId": "u001",
  "recordId": "backend-model-record-id",
  "modelFileName": "AGV.fs",
  "loadInUI": false
}
```

后端调用 MCP 工具：

```text
loadRemoteSimulationModel
```

后端返回给前端：

```json
{
  "success": true,
  "code": "OK",
  "message": "success",
  "data": {
    "recordId": "backend-model-record-id",
    "modelId": "模型ID",
    "uiLoaded": false,
    "status": "LOADED"
  }
}
```

说明：`recordId` 是后端模型库记录 ID，`modelId` 是 MCP Server 当前加载实例 ID，后续控制接口仍使用 `modelId`。服务器需要人工观察动画时传 `loadInUI=true`；无人值守部署传 `false`。

### 4.2 启动仿真

前端请求：

```http
POST /api/simulations/{modelId}/start
Content-Type: application/json
```

```json
{
  "userId": "u001",
  "showAnimation": false
}
```

后端调用 MCP 工具：

```text
startRemoteSimulation
```

只做高速计算时使用 `showAnimation=false`。需要 Web 端接收 MQTT JPEG 或结构化对象动画帧时使用 `showAnimation=true`；它不要求模型以桌面 UI 模式加载。

Web 动画启动前建议先调用：

```text
listRemoteSimulationAnimationLayers
selectRemoteSimulationAnimationLayer
```

浏览器显示截图时订阅二进制 `frameTopic`；重建数字孪生动画时订阅 JSON `objectFrameTopic`。完整协议见 `05_MQTT浏览器动画接口说明.md`。

### 4.3 查询状态

前端请求：

```http
GET /api/simulations/{modelId}/status?userId=u001
```

后端调用 MCP 工具：

```text
getRemoteSimulationStatus
```

前端可以轮询，建议 MVP 先用 1-2 秒间隔。

### 4.4 查询结果摘要和分页明细

前端请求：

```http
GET /api/simulations/{modelId}/snapshot?userId=u001&runId=xxx
```

后端调用 MCP 工具：

```text
getRemoteSimulationResultSnapshot
```

如果前端没有 runId，可以让后端传空字符串。该接口返回基础指标、体量较小的汇总结果和 `datasets` 目录，不再返回全部明细。

读取明细时，后端循环调用：

```text
getRemoteSimulationResultDatasetPage(userId, modelId, runId, dataset, offset, limit)
```

建议 `limit=200` 到 `500`，最大不能超过 1000。根据 `hasMore` 和 `nextOffset` 继续读取下一页。

## 5. 前端按钮禁用建议

| 状态 | 加载 | 启动 | 暂停 | 恢复 | 停止 | 重置 | 卸载 | 结果 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 未加载 | 可用 | 禁用 | 禁用 | 禁用 | 禁用 | 禁用 | 禁用 | 禁用 |
| LOADED | 禁用 | 可用 | 禁用 | 禁用 | 禁用 | 可用 | 可用 | 可用 |
| RUNNING | 禁用 | 禁用 | 可用 | 禁用 | 可用 | 禁用 | 可用 | 可用 |
| PAUSED | 禁用 | 禁用 | 禁用 | 可用 | 可用 | 禁用 | 可用 | 可用 |
| FINISHED | 禁用 | 可用 | 禁用 | 禁用 | 禁用 | 可用 | 可用 | 可用 |
| STOPPED | 禁用 | 可用 | 禁用 | 禁用 | 禁用 | 可用 | 可用 | 可用 |
| FAILED | 禁用 | 视情况 | 禁用 | 禁用 | 禁用 | 可用 | 可用 | 可用 |

说明：

- `unloadRemoteSimulationModel` 对 `RUNNING/PAUSED` 会先 stop，再卸载。
- 但为了交互明确，前端仍建议先让用户点停止，再点卸载。

## 6. 常见错误处理

### USER_MODEL_LIMIT_EXCEEDED

含义：同一用户已经加载了一个模型。

前端提示建议：

```text
当前用户已有模型加载，请先卸载当前模型后再加载新模型。
```

### GLOBAL_MODEL_LIMIT_EXCEEDED

含义：全局已加载模型超过 10 个。

前端提示建议：

```text
当前仿真服务已达到模型加载上限，请稍后再试或联系管理员释放模型。
```

### GLOBAL_RUNNING_LIMIT_EXCEEDED

含义：全局运行中模型超过 5 个。

前端提示建议：

```text
当前运行任务较多，请等待其他仿真结束后再启动。
```

### MODEL_NOT_FOUND

含义：`modelId` 不存在，或不是当前 `userId` 加载的模型。

前端处理建议：

- 清空当前本地模型状态。
- 提示用户重新加载模型。

### INVALID_STATE

含义：当前状态不允许执行该操作。

前端处理建议：

- 立即刷新状态。
- 按最新状态重新启用/禁用按钮。

## 7. 联调 Checklist

后端侧：

- MCP Server 已启动。
- `initialize` 正常。
- `tools/list` 能看到远程仿真工具。
- 后端不会把真实 MCP API key 返回给前端。
- 后端会解析 `result.content[0].text`。
- 后端会把业务 JSON 中的 `success/code/message/data` 返回给前端。

前端侧：

- 能展示 `LOADED/RUNNING/PAUSED/FINISHED/STOPPED/FAILED`。
- 按状态禁用按钮。
- 能展示错误码和 message。
- 能展示结果快照。
- 查询状态轮询不会过于频繁。

共同约定：

- `userId` 由后端认证体系生成或映射，不建议让前端随意传。
- `modelFileName` 建议由后端上传/存储模块生成，前端不要直接拼接本机路径。
- 结果页先展示第一层摘要；逐件结果、WIP 时间线、Lean 明细和 Energy 功率曲线通过第二层分页接口按需加载。
